# C64 Keycap Handling Tray
A tray for handling C64, VIC-20 and C16 keycaps while keyboard maintainance

This is a by-product of my <a href="https://github.com/svenpetersen1965/C64-Keyboard">C64 keyboard</a> project and is derived from the UV-printing tray for DSA keycaps.

It is helpful for keeping the overview of the keycaps while keyboard maintenance and prevent them from tipping over. This makes the installation much easier.
